# 🤖 Ücretsiz AI Yönlendirici (AI Router)

Bu uygulama, kullanıcının yapmak istediği işi analiz ederek onu en uygun Yapay Zeka aracına (Claude, Midjourney, Perplexity vb.) yönlendirir.

## 🚀 Özellikler
- **Gemini 1.5 Flash API** ile akıllı niyet analizi.
- **Streamlit** tabanlı kullanıcı dostu arayüz.
- Tamamen ücretsiz altyapı.
